# UtaBloom（仮称）｜Sing Your Song.

**あなたの歌を、あなたらしく花開かせる。**

歌詞に歌唱記号、発音注釈、解釈メモを重ねて、自分らしい歌唱表現を育てる歌唱ノートの試作版です。

**[UtaBloomを開く（GitHub Pages）](https://mosh20136-ops.github.io/utanote-preview/)**

## ご利用前に

- 現在のバージョン：**v3.14.6**
- 名称は仮称です。旧名称はUtaNoteです。
- 登録データは使っているブラウザ内に保存されます。端末をまたいだ自動同期はありません。
- 大切な内容を記録する前に、曲一覧のJSONバックアップ機能をご確認ください。
- テストには自作の短い歌詞などを使ってください。
- 現在のURLに残る `utanote-preview` は、以前の共有リンクを有効に保つため変更していません。
